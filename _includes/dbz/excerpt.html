{%- comment -%} Plain-text excerpt for a post card, with inline code preserved. {% include dbz/excerpt.html post=post words=45 %} Why this is not simply `strip_html | truncatewords`: post bodies are Asciidoctor output, and stripping every tag turns `log.mining.batch.size.*` into bare prose that is indistinguishable from the sentence around it. But the tags cannot merely be left in place either - truncatewords counts words, not markup, so it will happily cut through the middle of a tag. So the inline code tags are swapped for sentinels that survive stripping and truncation, then restored afterwards. Only the bare `` is protected. Asciidoctor emits `` for fenced blocks, which is left to be stripped: a code block dumped into a card is noise, and the post page is where it belongs. A closing sentinel is appended before restoration. When truncation happens to land inside a code span this closes it; otherwise it restores to a stray , which browsers ignore. {%- endcomment -%} {%- assign words = include.words | default: 45 -%} {%- if include.post.content contains "" -%} {%- assign source = include.post.excerpt -%} {%- else -%} {%- assign source = include.post.content -%} {%- endif -%} {%- assign text = source | replace: '', '[[dbz-code]]' | replace: '', '[[/dbz-code]]' | strip_html | truncatewords: words -%} {{- text | append: '[[/dbz-code]]' | replace: '[[dbz-code]]', '' | replace: '[[/dbz-code]]', '' -}}
