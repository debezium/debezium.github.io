{%- comment -%} Responsive column classes for a card grid, chosen from how many cards it holds.
One, two or four cards get two columns, so a short grid does not leave an empty third column and four go 2x2 rather than 3 + 1. Anything else gets three columns on wide screens. The class names are written out in full because the Tailwind build only finds names that appear literally in the source; ones assembled at render time would lose their styling. {%- endcomment -%} {%- assign dbz_grid_count = include.count | plus: 0 -%} {%- if dbz_grid_count <= 2 or dbz_grid_count == 4 -%} md:grid-cols-2 {%- else -%} md:grid-cols-2 xl:grid-cols-3 {%- endif -%}
