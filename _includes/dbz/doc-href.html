{%- comment -%} Resolves the documentation link for an entry in _data/databases.yml. {% include dbz/doc-href.html href=item.href since=item.since %} sets dbz_doc_href. Entries always link to /documentation/reference/stable/, but a connector that is new in a series that has not had a stable release yet has no page in the stable docs. For such an entry `since` names that series, and while none of its releases is stable the /stable/ part of the link is pointed at that series' docs instead. Once the series ships a stable release the link goes back to /stable/ by itself, so nothing has to be edited when the version moves on. The release data lookup matches _includes/dbz/release-context.html: Jekyll strips the dot from _data/releases directory names, so series "3.8" is keyed "38". An unknown series leaves the link unchanged. {%- endcomment -%} {%- assign dbz_doc_href = include.href -%} {%- if include.href and include.since -%} {%- assign sinceSeries = include.since | append: "" -%} {%- assign sinceKey = sinceSeries | replace: ".", "" -%} {%- assign sinceDetails = site.data.releases[sinceKey] -%} {%- if sinceDetails -%} {%- assign sinceStable = false -%} {%- for release in sinceDetails -%} {%- if release[1].stable -%}{%- assign sinceStable = true -%}{%- endif -%} {%- endfor -%} {%- unless sinceStable -%} {%- assign sincePrefix = "/documentation/reference/" | append: sinceSeries | append: "/" -%} {%- assign dbz_doc_href = include.href | replace_first: "/documentation/reference/stable/", sincePrefix -%} {%- endunless -%} {%- endif -%} {%- endif -%}
