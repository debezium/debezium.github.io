Two things this has to get right: Four posts credit several authors as a comma separated list with inconsistent spacing ("hpgrahsl,gmorling" but "jiazhai, StreamNative"), hence the `remove: " "` before splitting. The href downcases the id, matching _plugins/authors.rb, which creates the directory from the downcased id. Author ids are not all lowercase (StreamNative, SeanRooooney). Keeping the two in step matters: tags.rb built its pages at raw tag names while the links slugified, and nine tag links 404'd as a result. authors.yaml is keyed as written in front matter, so the display lookup uses the id unchanged and falls back to the raw id when there is no entry - which is the case for StreamNative.
