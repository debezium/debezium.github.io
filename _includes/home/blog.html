{%- comment -%} Featured blog posts, always exactly `count` cards. A post counts as featured here only when it has `featured: true` in its front matter AND was published within the last `featured_days` days. The flag is never cleared, so without the time box a two-year-old post could still be billed as featured on the landing page. The recent featured posts are picked first, up to `count`. Any cards left over are filled with the newest posts not already picked, flagged or not. So the section can be all featured, a mix, or (when nothing featured is recent) simply the newest posts. Whatever the mix, the cards are shown newest first. "Now" is the build time, so the window moves only when the site is rebuilt. {%- endcomment -%} {%- assign cfg = site.data.homepage.sections.blog -%} {%- assign featuredDays = cfg.featured_days | default: 180 -%} {%- assign windowSeconds = featuredDays | times: 86400 -%} {%- assign featuredCutoff = site.time | date: "%s" | plus: 0 | minus: windowSeconds -%} {%- assign post_pool = "" | split: "" -%} {%- assign shownUrls = "|" -%} {%- for post in site.posts -%} {%- if post_pool.size >= cfg.count -%}{%- break -%}{%- endif -%} {%- assign postSeconds = post.date | date: "%s" | plus: 0 -%} {%- if post.featured == true and postSeconds >= featuredCutoff -%} {%- assign post_pool = post_pool | push: post -%} {%- assign shownUrls = shownUrls | append: post.url | append: "|" -%} {%- endif -%} {%- endfor -%} {%- for post in site.posts -%} {%- if post_pool.size >= cfg.count -%}{%- break -%}{%- endif -%} {%- assign urlKey = "|" | append: post.url | append: "|" -%} {%- unless shownUrls contains urlKey -%} {%- assign post_pool = post_pool | push: post -%} {%- endunless -%} {%- endfor -%} {%- comment -%} Featured status decides which posts make the cut, not where they sit: the cards always read newest first, left to right. {%- endcomment -%} {%- assign post_pool = post_pool | sort: "date" | reverse -%}
