We're pleased to announce the release of *Debezium 3.5.2.Final*, a maintenance release in the 3.5 stable series.
This release upgrades the Kafka dependency to version 4.1.2 and addresses several bug fixes across connectors, including improvements to CockroachDB default value handling and table filtering, and more.
Read on for the full details!

=== Debezium Core

==== Upgrade to Kafka 4.1.2

The Kafka client dependency has been upgraded to version 4.1.2, bringing the latest upstream fixes and improvements.
This ensures Debezium remains compatible with the most recent Kafka release in the 4.1.x series.
(https://github.com/debezium/dbz/issues/2008[dbz#2008])

[id="new-features-and-improvements-debezium-cockroachdb"]
=== Debezium for CockroachDB

==== Support for typed column DEFAULT values

The connector previously failed to start when a captured table contained non-string column DEFAULT values such as `INT DEFAULT 0`, `BOOL DEFAULT false`, or `TIMESTAMPTZ DEFAULT current_timestamp()`.
The raw string from JDBC metadata was passed directly to the schema builder without conversion to the column's Java type, causing a `DataException`.

A new `CockroachDBDefaultValueConverter` now properly parses DEFAULT values into their expected Java types, matching the behavior of other connectors.
(https://github.com/debezium/dbz/issues/1975[dbz#1975])

== Other fixes

// [Debezium Core]
* Spanner NullPointerException in ApproximateStructSizeCalculator during null-offset heartbeat dispatch (https://github.com/debezium/dbz/issues/1944[dbz#1944])
