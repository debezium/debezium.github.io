All notable changes for Debezium releases are documented in this file. Release numbers follow Semantic Versioning.

  • Release 3.7.0.Alpha1 (July 30th 2026)

Release 3.7.0.Alpha1 (July 30th 2026)

See the complete list of issues.

Kafka compatibility

This release has been built against Kafka Connect 4.3.0 and has been tested with version 4.3.0 of the Kafka brokers. See the Kafka documentation for compatibility with other versions of Kafka brokers.

Upgrading

Before upgrading any connector, be sure to check the backward-incompatible changes that have been made since the release you were using.

When you decide to upgrade one of these connectors to 3.7.0.Alpha1 from any earlier versions, first check the migration notes for the version you’re using. Gracefully stop the running connector, remove the old plugin files, install the 3.7.0.Alpha1 plugin files, and restart the connector using the same configuration. Upon restart, the 3.7.0.Alpha1 connectors will continue where the previous connector left off. As one might expect, all change events previously written to Kafka by the old connector will not be modified.

If you are using our container images, then please do not forget to pull them fresh from Quay.io.

Breaking changes

JDBC sink datatype mapping rules were modified to guarantee consistency in MySQL to MySQL scenarios (debezium/dbz#2102).

MySQL connector type mapping rules for integers were modified to guarantee that the value can be represent in the complete range regardless of signedness (debezium/dbz#2235).

ByLogicalTableRouter SMT now supports MongoDB connector. To reflect this fact it was renamed to ToLogicalTopicRouter and the original name is deprecated (debezium/dbz#197).
