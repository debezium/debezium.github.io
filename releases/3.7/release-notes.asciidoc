== *Release 3.7.0.Alpha1* _(July 30th 2026)_

See the https://github.com/orgs/debezium/projects/5/views/6?filterQuery=status%3AReleased+iteration%3A3.7.0.Alpha1[complete list of issues].

=== Kafka compatibility

This release has been built against Kafka Connect 4.3.0 and has been tested with version 4.3.0 of the Kafka brokers.
See the https://kafka.apache.org/documentation/#upgrade[Kafka documentation] for compatibility with other versions of Kafka brokers.


=== Upgrading

Before upgrading any connector, be sure to check the backward-incompatible changes that have been made since the release you were using.

When you decide to upgrade one of these connectors to 3.7.0.Alpha1 from any earlier versions,
first check the migration notes for the version you're using.
Gracefully stop the running connector, remove the old plugin files, install the 3.7.0.Alpha1 plugin files, and restart the connector using the same configuration.
Upon restart, the 3.7.0.Alpha1 connectors will continue where the previous connector left off.
As one might expect, all change events previously written to Kafka by the old connector will not be modified.

If you are using our container images, then please do not forget to pull them fresh from https://quay.io/organization/debezium[Quay.io].


=== Breaking changes

JDBC sink datatype mapping rules were modified to guarantee consistency in MySQL to MySQL scenarios (https://github.com/debezium/dbz/issues/2102[debezium/dbz#2102]).

MySQL connector type mapping rules for integers were modified to guarantee that the value can be represent in the complete range regardless of signedness (https://github.com/debezium/dbz/issues/2235[debezium/dbz#2235]).

`ByLogicalTableRouter` SMT now supports MongoDB connector. To reflect this fact it was renamed to `ToLogicalTopicRouter` and the original name is deprecated (https://github.com/debezium/dbz/issues/197[debezium/dbz#197]).
