== *Release 3.6.2.Final* _(September 1st 2026)_

See the https://github.com/orgs/debezium/projects/5/views/6?filterQuery=status%3AReleased+iteration%3A3.6.2.Final[complete list of issues].

=== Kafka compatibility

This release has been built against Kafka Connect 4.3.0 and has been tested with version 4.3.0 of the Kafka brokers.
See the https://kafka.apache.org/documentation/#upgrade[Kafka documentation] for compatibility with other versions of Kafka brokers.


=== Upgrading

Before upgrading any connector, be sure to check the backward-incompatible changes that have been made since the release you were using.

When you decide to upgrade one of these connectors to 3.6.2.Final from any earlier versions,
first check the migration notes for the version you're using.
Gracefully stop the running connector, remove the old plugin files, install the 3.6.2.Final plugin files, and restart the connector using the same configuration.
Upon restart, the 3.6.2.Final connectors will continue where the previous connector left off.
As one might expect, all change events previously written to Kafka by the old connector will not be modified.

If you are using our container images, then please do not forget to pull them fresh from https://quay.io/organization/debezium[Quay.io].


=== Breaking changes

There are no breaking changes in this release.

== *Release 3.6.0.Alpha1* _(April 22nd 2026)_

=== Kafka compatibility

This release has been built against Kafka Connect 4.1.1 and has been tested with version 4.1.1 of the Kafka brokers.
See the https://kafka.apache.org/documentation/#upgrade[Kafka documentation] for compatibility with other versions of Kafka brokers.


=== Upgrading

Before upgrading any connector, be sure to check the backward-incompatible changes that have been made since the release you were using.

When you decide to upgrade one of these connectors to 3.6.0.Alpha1 from any earlier versions,
first check the migration notes for the version you're using.
Gracefully stop the running connector, remove the old plugin files, install the 3.6.0.Alpha1 plugin files, and restart the connector using the same configuration.
Upon restart, the 3.6.0.Alpha1 connectors will continue where the previous connector left off.
As one might expect, all change events previously written to Kafka by the old connector will not be modified.

If you are using our container images, then please do not forget to pull them fresh from https://quay.io/organization/debezium[Quay.io].


=== Breaking changes

Order of enum column options in PostgreSQL schema was not defined.
This could lead to fake schema change during the processing.
The order now follows the logical order as defined in database (https://github.com/debezium/dbz/issues/1331[debezium/dbz#1331]).

MongoDB could not handle collections whose names started with number.
This is no longer a problem but the Avro naming conversion is now applied separately for each component of schema name instead of the final schema name (https://github.com/debezium/dbz/issues/305[debezium/dbz#305]).
